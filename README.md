## Назва та короткі відомості про проект
- **Назва проекту:** Розробка та аналіз індивідуального програмного модуля
- **Опис:** Навчальний проект для виконання індивідуального завдання, освоєння базових інструментів розробки та роботи з системою контролю версій Git.
- **Основна мета:** Практична реалізація алгоритмів на мові Python, збереження та синхронізація коду через GitHub.
- **Стек технологій:** Python, VS Code, Git, GitHub, Anaconda.
